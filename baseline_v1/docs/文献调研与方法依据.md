# 文献调研与方法依据

本题不需要外部业务数据，外部调研主要用于确定调度问题类型与求解框架。

## 1. 问题类型定位

本题具有以下结构：

- 车间内工序存在固定先后关系，属于资源受限项目调度（RCPSP）结构。
- 同类设备存在多台可替代设备，属于柔性作业车间调度（FJSP）结构。
- 同一设备跨车间作业需要转运时间，且该转运时间取决于前后车间位置，等价于序列相关准备时间（sequence-dependent setup time）。

因此，本题可归入“小规模FJSP/RCPSP + 序列相关setup time + makespan最小化”的混合调度问题。

## 2. 求解方法选择

文献中常见方法包括：混合整数规划（MILP/MIP）、约束规划（CP/CP-SAT）、遗传算法、禁忌搜索、邻域搜索与调度生成机制。由于本题展开后只有27个工序、41个设备子任务，规模较小，采用MILP可以得到可证明最优解，而非仅给出启发式可行解。

## 3. 参考资料

1. SciPy Documentation: `scipy.optimize.milp`。该函数是HiGHS混合整数线性规划求解器封装，支持整数变量、上下界、线性约束与MIP gap控制。
   - https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html

2. Ku, W.-Y., Beck, J. C. *Mixed Integer Programming Models for Job Shop Scheduling: A Computational Analysis*。该研究比较了作业车间调度问题的多类MIP模型，并指出disjunctive formulation在JSP中表现突出。
   - https://www.researchgate.net/publication/301250537_Mixed_Integer_Programming_Models_for_Job_Shop_Scheduling_A_Computational_Analysis

3. Artigues, C., Lopez, P., Ayache, P.-D. *Schedule generation schemes for the job-shop problem with sequence-dependent setup times: dominance properties and computational analysis*。该研究关注带序列相关准备时间的JSP调度生成机制。
   - https://arxiv.org/abs/cs/0606043

4. Lan, L., Berkhout, J. *PyJobShop: Solving scheduling problems with constraint programming in Python*。该文指出PyJobShop支持柔性作业车间调度与资源受限项目调度等问题，并集成OR-Tools CP-SAT和IBM CP Optimizer。
   - https://arxiv.org/abs/2502.13483
