# 研究过程记录

## 1. 题目识别

题目为多车间集中整修的多工序协同作业问题。核心约束包括：

1. 每个车间内的工序必须按编号顺序完成。
2. 每道工序需要一类或两类设备完成。
3. 同一设备同一时刻只能服务一道工序。
4. 同一车间内转运时间忽略，跨车间转运时间不可忽略。
5. 设备工作持续时间按秒向上取整。

## 2. 数据处理

从附件中提取三类数据：工序流程、班组设备配置、车间距离。关键处理如下：

- C3-C5按题目说明重复三轮，展开为 C3_R1, C4_R1, C5_R1, C3_R2, C4_R2, C5_R2, C3_R3, C4_R3, C5_R3。
- 每个“工序-设备类型”拆分为一个设备子任务。
- 子任务持续时间计算公式：ceil(工程量/效率*3600)。
- 转运时间计算公式：ceil(距离/2)。

## 3. 模型选择

该问题同时具备柔性作业车间调度、资源受限项目调度、序列相关setup time三个特征。由于展开后规模为27个工序、41个设备子任务，适合用混合整数线性规划直接求解。

## 4. 变量设计

- S_j：工序j开始时间。
- T：全局最大完工时间。
- x_om：设备子任务o是否分配给设备m。
- y_abm：若a、b可由同一设备m处理，则y_abm=1表示a在b之前。

## 5. 约束设计

1. 子任务唯一设备分配。
2. 车间内部工序链约束。
3. 最大完工时间约束。
4. 初始从班组驻地到车间的到达约束。
5. 同一设备不重叠作业约束。
6. 同一设备跨车间转运时间约束。

## 6. 求解步骤

1. 对Q1、Q2、Q3分别建立固定设备MILP。
2. 第一阶段以最大完工时间T为目标求最优。
3. 第二阶段在T不变条件下最小化工序开始时间之和，使非关键任务尽量提前，输出更紧凑。
4. 对Q4先求C车间关键链下界，再与Q3结果比较。

## 7. Q4判断

C车间链不含初始转运的下界为123614s，最快设备从班组1到C的初始转运时间为230s，所以全局下界为123844s。Q3已达到123844s，因此增购设备不能缩短总工期。在“工期优先、成本次优”的准则下，Q4最优采购为0台。

## 8. 可复现性

核心代码位于 `code/model_solver.py`。运行后可重新生成五张结果表与汇总文件。模型参数全部在脚本中显式给出，便于检查和修改。
