# Q2 多车间调度

仅用班组 1 设备完成 A、B、C、D、E 五个车间全部整修任务，求最短完工时长。

- **规模**：5 车间、27 个工序实例（C 车间 C3-C5 循环 3 遍需展开）、跨车间运输时间。
- **新增约束**：
  - 同设备跨车间作业需计算运输时间 = 距离 / 移动速度（2 m/s），向上取整到秒。
  - 运输时间依赖设备前一工序所在车间与当前工序所在车间。
- **推荐解法**：元启发式（遗传算法 GA / 模拟退火 SA），编码 = 工序排序 + 设备分配；OR-Tools CP-SAT 带时限作为基准对照。
- **产出**：表 2（设备调度时刻表）+ 最短时长(s)。

> 难点：工序数 × 设备组合爆炸；C3-C5 循环展开后工序优先约束更复杂。
