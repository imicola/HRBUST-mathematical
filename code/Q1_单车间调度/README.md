# Q1 单车间调度

班组 1 独立完成 A 车间全部整修任务（A1→A2→A3），求最短完工时长。

- **规模**：3 道工序、A1/A2 需双设备协同、班组 1 设备池（自动化输送臂×4、工业清洗机×5、精密灌装机×5、自动传感多功能机×1、高速抛光机×1）。
- **推荐解法**：OR-Tools CP-SAT 精确求解（规模小，可证最优）；备用穷举/分支定界。
- **产出**：表 1（每台设备：设备编号、起止时间、持续工作时间、工序编号）+ 最短时长(s)。

> 关键约束：工序严格按 A1→A2→A3；双设备协同时两类设备各自独立完成全部工程量，取两者较晚完成时刻为工序完成时刻；同车间内同设备无运输时间。
