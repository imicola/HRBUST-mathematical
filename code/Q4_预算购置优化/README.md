# Q4 预算购置优化

追加 50 万元设备购置预算，联合确定「买什么设备 + 如何调度」使全部任务完工时间最短。

- **决策变量（双层）**：
  1. 购置方案：各班组补增各设备类型的台数，总费用 ≤ 500000 元。
  2. 调度方案：在新设备池下的工序-设备-班组分配与排序。
- **设备单价**：自动化输送臂 5 万、工业清洗机 4 万、精密灌装机 3.5 万、自动传感多功能机 8 万、高速抛光机 7.5 万。
- **推荐解法**：
  - 两阶段法：枚举/智能搜索高价值购置方案 → 对每个方案求解 Q3 规模调度 → 选最优。
  - 联合编码 GA：染色体同时含购置决策与调度决策。
  - 瓶颈分析启发式：先识别 makespan 瓶颈设备类型，预算优先补给瓶颈。
- **产出**：表 4（调度时刻表 + 班组）+ 表 5（购置方案）+ 最短时长(s) + 购置总费用。

> 难点：购置与调度强耦合，需证明购置方案的最优性（敏感性分析 + 界限论证）。
