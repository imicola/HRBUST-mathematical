## 三、模型正确性核验（逐约束）

v1 为单目标 MILP（`min T`），变量：`S_j`（工序开始，连续）、`T`（makespan）、`x_om`（子任务→设备分配，二元）、`y_abm`（同设备排序，二元），big-M=1e6 析取式。

| # | 约束 | v1 实现 | 核验结论 |
|---|---|---|---|
| A | 子任务唯一分配 | 每个子任务 `Σx_om=1`（限同型设备） | ✅ 正确 |
| B | 车间工序链 | `S[j2]-S[j1] >= maxdur[j1]` | ✅ 正确（依赖双设备同时起算） |
| C | makespan 定义 | `T - S_j >= maxdur[j]` ∀j | ✅ 正确 |
| D | 初始到达 | `S_j >= x_om·travel(base,ws)` | ✅ 对首工序有效；对非首工序冗余但无害 |
| E | **同设备不重叠+跨车间转运** | big-M 析取，含 `dur+transport` 间隔 | ✅ **正确**（见下） |
| — | 双设备协同 | 两子任务共用同一 `S_j`（强制同时开始） | ⚠️ 建模选择，见第四节 |

**约束 E（核心）符号验证**：当 `x_a=x_b=1`（同设备）时，`y=1 ⇒ S_b-S_a ≥ dur_a+transport(a.ws→b.ws)`；`y=0 ⇒ S_a-S_b ≥ dur_b+transport(b.ws→a.ws)`；不同设备时两式均松弛。✅ 严格正确。

**机器位置连续性**：全对析取 + 距离满足三角不等式 ⇒ 连续工序的转运约束经传递闭包自动满足，机器不会"瞬移"。✅ 无遗漏约束。

> Oracle 复核确认：逐约束验证无错误，析取式与转运处理正确，无关键遗漏约束。唯一可商榷是双设备同时性（建模选择，非 bug）。

## 四、双设备同时性假设分析

**假设内容**：需两类设备的工序，v1 令两类设备**同一时刻** `S_j` 开始，各自占用本类型时长，工序完工时刻 = `S_j + max(dur)`。

**(a) 是否符合题意**：题目假设(2)"两类设备都需要完成该工序所对应的工程量……不考虑两类设备之间的等待时间"。"不考虑等待时间"最自然解读为**并行/并发**，支持同时起算。该解读**可辩护、且是主流 FJSP 复合工序处理方式**。

**(b) 是否可能次优**：理论上同时性是限制（松弛后可行域更大，最优 makespan 只降不升）。一般 FJSP 中，当某类设备是全局瓶颈时，错峰起算可能腾出空闲窗口。**但对本实例：风险为零**——

> 关键洞察：C 车间工序链下界 `123614s`（见第六节）**与同时性假设无关**。它只是"严格顺序工序、每道至少耗时 max(dur)"的硬下界。Q3 在同时性模型下恰好达到 `123614+230=123844s`，故即使放松同时性也**不可能突破** 123844s。Q3/Q4 的最优性结论对同时性解读**稳健**。

**论文答辩建议**：主动声明"采用同时起算简化建模；由于解达到解析下界，该选择被证明非约束性"——把潜在弱点转化为严谨性亮点。

## 六、最优性独立证明（不依赖 MILP）

最强背书：用**纯解析的车间工序链下界**交叉证明，MILP 解恰好顶到下界。

### 6.1 Q1 = 41600s（A 车间链下界，紧致）

```
到达 A（班组1→A, 400m/2）: 200s
+ A1 max(5400 PFM, 4320 ACA)  : 5400s
+ A2 max(18000 HPM, 7200 ICM) : 18000s
+ A3 (18000 ASM)              : 18000s
= 41600s  ← 与 v1 Q1 完全一致 ⇒ Q1 解析可证最优
```

### 6.2 Q3/Q4 = 123844s（C 车间链下界，紧致）

```
C 链（严格顺序，不可并行，单机满载）:
  C1(10368) + C2(7406) + 3×[C3(6480)+C4(14400)+C5(14400)]
  = 17774 + 105840 = 123614s
+ 最短初始到达 C（min_i travel(Crew_i→C)）: 230s   ⚠️ 待确认是两班组最小值
= 123844s  ← 与 v1 Q3 完全一致 ⇒ Q3 解析可证最优
```

**Q4 推论**（严密）：购买设备只能增加同型设备并行**不同工序**的能力，**无法缩短任一单工序的 max(dur)**（题目示例"精密灌装机完成 300m³"明确为单机满工作量，禁止工序内拆分并行）。C 链是车间内严格顺序、与设备数无关的不可压缩路径 ⇒ **任何采购都不能使 makespan < 123844s**。而 Q3 已达 123844s ⇒ **Q4 最优采购 = 0 台**，最优 makespan = 123844s。结论严密。

> ⚠️ **Q2 = 163764s 是最薄弱环节**：目前**无独立下界**，最优性仅靠 MILP（0% gap）+ 同时性假设。建议核验 Q2 的关键路径（大概率仍是某车间链），补一条解析下界消除该弱点。
> ⚠️ **C 到达 230s 待确认**：需核验是否为两班组到 C 的最小转运（班组2→C=620m=310s > 230s，故 230 确为最小，下界紧致 ✅——已由距离表确认）。

## 八、算法方向对比：v1 MILP vs 原计划 CP-SAT+GA

> 原计划（`solve/README.md`）：OR-Tools CP-SAT 精确求解 + DEAP 遗传算法，主打 Q2-Q4 元启发式。
> 核心事实：**本实例 MILP 4.73s 证明全局最优**，"可扩展性"卖点在本赛题规模下基本失效。

| 维度 | 方向 A：v1 MILP（scipy/HiGHS） | 方向 B：原计划 CP-SAT + GA |
|---|---|---|
| **最优性证明** | ✅ 全局最优(0% gap) + Q1/Q4 独立下界 | CP-SAT 可证最优；**GA 无任何保证** |
| **本实例求解速度** | 4.73s（已证最优） | CP-SAT 秒级；GA 需调参且不保证 |
| **建模表达力** | big-M 析取（有 scaling 告警） | CP-SAT 原生 `NoOverlap`/区间变量，**更干净、无 big-M** |
| **序列相关转运** | big-M + transport 项（可行但笨重） | 原生 transition cost，**更自然** |
| **可扩展性余量** | ~40+ ops 吃紧 | CP-SAT 平滑扩展至 100+ ops；GA 线性 |
| **Q4 采购建模** | v1 用下界论证回避（需补显式模型） | GA/枚举外层 + CP-SAT 内层，天然适配双层决策 |
| **完成度** | ✅ 已完成并验证 | ❌ 未开始 |
| **论文丰富度** | 单方法，偏薄 | 多方法对比 + 敏感性分析，**占优** |
| **GA 主力的风险** | — | 若 GA 解 ≠ 最优解，论文出现不一致（**真实风险**） |

**文献依据（Librarian）**：27 ops 远低于 MILP 在 JSP 上"可舒适证明最优"的门槛（~15×15=225 ops）；CP-SAT 在调度基准（Taillard 等）上普遍优于 MILP，尤其规模增大时；GA 仅在大规模/不要求证明时才有价值。本实例两套精确方法都秒级证最优，**GA 在本题是"装饰性"而非"必要性"**。

1. **答案底座 = v1 已证最优结果**（Q1=41600, Q2=163764, Q3=123844, Q4=采购0）。**不要用 GA 重算headline答案**——会引入次优风险且无增益。

3. **DEAP GA 降级为"对比/扩展性"启发式**：仅用于论文"算法对比 + 大规模敏感性"叙事，**明确标注非最优**，并必须验证在本实例复现最优解（本规模 GA 极易命中，风险低）。
4. **Q4 补显式采购模型**（见 9.2）。
