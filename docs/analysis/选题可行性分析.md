## 一、三题概览

### A 题 · 煤矿巷道支护问题（力学 / 岩土工程）

**主题**：建立锚杆「预紧力矩 T ↔ 预紧力 P」的转换与优化模型，服务于巷道支护的精准设计与安全施工。

**题目含义**：锚杆支护靠拧紧螺母施加预紧力矩 T，经螺纹传动转为轴向预紧力 P，使围岩由二向受力转为三向受力实现主动支护。但 T↔P 并非线性，且过大预紧力会导致锚杆屈服 / 托盘压陷。围绕 4 个问题展开：

1. **线性段建模 + 临界力矩**：标准实验下 T=K·P·d，求不同直径扭矩系数 K（表1）；用直径 20mm 实测数据（表2 岩石、表3 煤体）求进入稳态线性段的临界预紧力矩。
2. **最大允许力矩 + 钢带必要性**：基于锚杆强度极限、锚固系统极限、围岩压陷极限（Winkler 弹性地基模型），建立通用参数化 Tmax 模型，判断工况 A/B 是否必须加钢带（表4）。
3. **偏心受力修正**：偏心距 e 引发附加弯矩，螺纹段同时承受轴向拉应力 + 弯曲应力 + 扭转剪应力，用 Von Mises 准则建立 Tmax(e) 模型并分析附录 3 简化假设的局限。
4. **围岩等级优化**：以普氏系数 f 为自变量，建立不触发任何失效约束的最优预紧力矩 Topt(f) 模型，分析软岩/中硬/坚硬围岩的主控失效模式。

**数据特征**：小规模实验/工况表格（表1~表4，几十行），数据干净、确定性强。

### B 题 · 多工序协同作业问题（运筹 / 调度优化）

**主题**：对 5 个车间（A~E）开展集中整修，每车间工序严格有序、部分工序需两类设备协同、设备跨车间转运有时间成本，求最短完工时间（Makespan）及设备调度/购置方案。

**题目含义**：典型的柔性作业车间调度（FJSP）+ 设备运输路由耦合问题。4 个递进问题：

1. 班组 1 独立完成 A 车间（单车间调度，暖身）。
2. 班组 1 完成 A~E 五车间（多车间 + 跨车间运输时间）。
3. 班组 1+2 共同完成五车间（双班组资源分配）。
4. **追加 50 万元设备购置预算**，联合确定「买什么设备 + 如何调度」使总时长最短（预算约束下的设备扩充 + 调度联合优化）。

**数据特征**：工序流程表（22 行）、班组配置表（5 类设备 ×2 班组）、车间距离表。数据规模小，但组合爆炸严重。

### C 题 · 边坡预警问题（数据分析 / 机器学习 / 时序）

**主题**：从强噪声、多断点的多源监测时序中，精准识别边坡「三段式形变」阶段转换节点，构建滑坡提前预警模型。

**题目含义**：覆盖完整数据科学流水线的 5 个问题：

1. **数据校正**：附件1 同点两路位移数据（A 光纤含零漂偏移、B 振弦为基准），建立 A→B 校正模型，交叉验证评估，给出 5 个验证点。
2. **阶段转换点识别**：附件2 位移时序，识别「缓慢匀速 → 加速 → 快速」两处转换节点，区分噪声跳变与真实转换；分阶段建模并求各段平均位移速度（mm/h）。
3. **去噪 + 缺失填补 + 异常检测 + 关联分析**：附件3 五变量时序（降雨/孔隙水压/微震/深部位移/表面位移），含异常与缺失；去噪补齐 → 单变量及多变量共同异常检测 → 定量分析表面位移与其他变量的关联（训练集建模，实验集预测 + 散点图）。
4. **分阶段位移预测**：附件4 训练集（含三阶段，5 特征：降雨/孔隙水压/微震/爆破距离/药量）建分阶段模型；实验集（阶段标签已给）预测表面位移并绘时序图、补全预测表。
5. **特征选择 + 预警机制**：附件5 七维数据，从 6 类变量中选 5 类建最优组合模型；以表面位移速度为指标，分阶段构建滑坡预警阈值机制。

**数据特征**：大规模时序（附件1~5，每个约 1 万行 ×多列，10 分钟采样），含噪声、缺失、跳变——典型的真实工程监测数据。

## 二、四维度评分（1~10 分）

> 评分约定：
> - **难度**：数字越大 = 越难（对解题者不利）
> - **可行性**：数字越大 = 越容易高质量完成（有利）
> - **论文丰富度**：数字越大 = 论文越能写得丰满出彩（有利）
> - **得分难度**：数字越大 = 越难拿到高分（不利）

| 维度 | A 题 煤矿支护 | B 题 多工序调度 | C 题 边坡预警 |
|:----:|:----:|:----:|:----:|
| **难度**（越大越难） | 7 | 9 | 6 |
| **可行性**（越大越易完成） | 7 | 5 | **9** |
| **论文丰富度**（越大越丰满） | 6 | 8 | **10** |
| **得分难度**（越大越难拿分） | 7 | 9 | **5** |
| **综合（加权倾向可行+丰富）** | 6.5 | 6.0 | **9.0** |

### 评分理由

**A 题**
- 难度 7：力学推导门槛高（Von Mises、Winkler 地基、偏心弯矩），附录虽给公式但需吃透力学原理与简化假设的局限性分析；Q4 主控失效模式分析需要工程判断。
- 可行性 7：确定性问题、公式齐全、数据小且干净，理论上可逐步推导；但卡在「力学理解偏差」则全盘被动。
- 论文丰富度 6：以公式推导 + 数值计算为主，图表少（曲线、应力云图有限），方法栈相对单一，难有「亮眼」可视化。
- 得分难度 7：答案多为确定数值，评委可核验；力学细节错一处连锁失分，容错率低。

**B 题**
- 难度 9：NP-hard 的 FJSP + 跨车间运输 + 双设备协同；**Q4 预算约束下「购置 + 调度」联合优化是研究级难题**，4 天内极难给出近优解。
- 可行性 5：Q1 可做，Q2~Q4 组合爆炸，启发式算法调参/收敛不确定，**极易做不完或结果可信度低**。
- 论文丰富度 8：甘特图、调度流程、算法对比、敏感性分析可写得充实；但核心产出就是一组调度表/时刻表。
- 得分难度 9：最优 Makespan 难验证，各队结果差异大，无法确信自己是否最优；约束遗漏（运输时间、双设备协同）直接致错。

**C 题**
- 难度 6：每个子问题都是标准数据分析任务，无高门槛领域知识，方法成熟公开。
- 可行性 9：方法栈极其成熟（ruptures / scipy / xgboost / shap / sklearn），参考代码海量，**可 100% 完整交付**。
- 论文丰富度 10：5 个子问题层层递进，去噪/变点/异常/预测/预警全覆盖，配合大量科研级图表（时序、散点、热力图、SHAP），论文天然丰满。
- 得分难度 5：多模型对比 + 部分分易拿，标准方法多、容错高，「完整度」本身就是强竞争力。

## 三、夺奖策略修正：**改选 B 题 · 多工序协同作业问题**

### 为什么从 C 改成 B —— 目标决定策略

初版按「求稳练手 / 保底」目标推荐 C（可行性最高、好做完）。但当目标切换为**「脱颖而出夺顶奖」**时，选题的第一优先级从「可行性」变为「**竞争密度 + 区分度**」，逻辑近乎反转：

- **获奖是相对排名游戏**：决定名次的不是题目难不难，而是「你 vs 选同一题的其他队」的竞争烈度。
- **C 题的陷阱**：好做 = 大家都做完 = 你要赢的是几百个"完整方案"，必须做到 TOP 5% 才能出头，靠"完整"赢不了。
- **B 题的甜点**：选的人比 C 少一半（A:B:C ≈ 1:2:3），只需赢几十个队；且有客观最优解（Makespan 可直接比较），**区分度极高**——做出近优解 vs 做不出的队，评委一眼分高下。

### 改选 B 的核心理由

1. **竞争密度低、区分度高**：B 题有标准答案区间，硬实力可直接转化为名次；甘特图 + 调度方案 + 算法对比让"强"一目了然。
2. **论文丰富度足够（8/10）**：甘特图、关键路径、设备利用率、算法收敛曲线、购置方案敏感性分析，展示空间大。
3. **团队优化算法能力可覆盖**：B 题虽 NP-hard，但团队掌握 GA/SA/OR-Tools 即可给出强竞争力近优解；风险可控。
4. **反共识红利**：同样的实力，选人少的题相对排名更靠前——这是夺奖的杠杆。

### B 题大概内容与特色

**内容**：5 个车间（A~E）集中整修，每车间工序严格有序、部分工序需两类设备协同（各自独立完成工程量）、设备跨车间转运有时间成本。4 个递进问题：单班组单车间 → 单班组 5 车间 → 双班组 5 车间 → 追加 50 万元预算的「设备购置 + 调度」联合优化。本质是**柔性作业车间调度（FJSP）+ 运输路由耦合**。

**特色（亮点抓手）**：
- **分层求解**：Q1 用 OR-Tools CP-SAT 精确求解证最优，Q2~Q4 用遗传算法（MSOS 编码）求近优，CP-SAT 作基准对照——"精确 + 启发式"双线增强可信度。
- **约束建模严谨**：双设备协同（取 max 完成时刻）、C 车间 C3-C5 循环 3 遍、跨车间运输 setup time 全覆盖。
- **Q4 双层决策**：瓶颈设备分析驱动购置方案剪枝 + 内层 GA 调度，给出可解释的"买什么、怎么排"。
- **可视化夺分**：科研级甘特图（按设备/车间着色、标注运输时间与关键路径）。

### 风险与对策

| 风险 | 对策 |
|:-----|:-----|
| Q4 双层优化做不完 | Q1~Q3 先确保完整（占大头）；Q4 用瓶颈启发式给 1~2 个合理购置方案即可，不求穷举 |
| 近优解难以证明最优性 | 用 CP-SAT 下界 + 多次独立运行稳定性 + 收敛曲线佐证解质量 |
| 约束遗漏（运输/双设备协同） | common/instance.py 统一建模，decode 统一解码，各算法口径一致 |
| GA 收敛差 | 采用 GA + 禁忌搜索混合，关键参数（种群/代数/交叉变异率）做敏感性分析 |

> 备注：原"C 题求稳分析"与四维度评分表保留于上，作为策略对比的参照——它准确刻画了"求稳"场景下的最优解，但不再适用于"夺奖"目标。

## 四、C 题（边坡预警）方法栈 —— 求稳参照（已弃选）

> 以下为初版针对 C 题的方法栈，保留备查。最终已改选 B 题，B 题求解策略见 `code/` 各子目录 README。

### 题目大概内容与特色

**内容**：围绕边坡「三段式形变」（缓慢匀速 → 加速 → 快速）演化规律，从多源监测时序（位移、降雨、孔隙水压力、微震、深部位移、爆破参数、干湿入渗系数）中，完成数据校正、阶段识别、去噪补齐、异常检测、位移预测、特征选择与滑坡预警阈值设计的全链条建模。

**特色（亮点抓手）**：
- **变点检测 + 分阶段建模**：用 PELT/BinSeg 识别阶段转换，为不同阶段训练独立模型（MoE 思想）。
- **多源数据融合**：降雨 ↔ 孔隙水压 ↔ 微震 ↔ 位移的耦合关联，SHAP 定量归因各因素贡献。
- **可解释预测**：XGBoost/LightGBM 主力 + SHAP 解释，避免「黑盒丢数据」的数模大忌。
- **工程化预警机制**：以位移速度为指标，分阶段设定黄/红预警阈值（切线角法 + 分位数法），具备实际工程可解释性。

## 六、C 题风险与对策（求稳参照）

| 风险 | 对策 |
|:-----|:-----|
| C 题竞争激烈（选的人多） | 在「多模型对比 + SHAP 解释 + 科研级可视化 + 灵敏度分析」上做满，靠完整度与可解释性突围 |
| 阶段转换点判据主观 | 给出客观量化准则（速度阈值 + 统计检验），并做鲁棒性验证 |

| 论文模型割裂 | 全程统一方法主线（分阶段 + 数据驱动），各问呼应不脱节 |
