## 1. 总体写作定位

### 1.1 论文核心观点

本题不是只给出一组可行调度，而是构建了一个可验证的最优调度方案：

```text
Q1 = 41600s  = 11:33:20
Q2 = 163764s = 45:29:24
Q3 = 123844s = 34:24:04
Q4 = 123844s = 34:24:04，最优采购费用 0 元
```

四问的证明结构为：

| 问题 | 可行解来源 | 最优性依据 | 论文中应强调 |
|---|---|---|---|
| Q1 | 完整 MILP 调度表 | A 车间工序链下界 | 单车间链式任务直接达到下界 |
| Q2 | 完整 MILP 调度表 | 双瓶颈资源松弛下界 | 单班组下高速抛光机与自动传感多功能机决定工期 |
| Q3 | 完整 MILP 调度表 | C 车间关键链下界 | 双班组后全局瓶颈转移到不可压缩的 C 链 |
| Q4 | 显式采购 CP-SAT 验证 | C 链下界 + 字典序最小采购费用 | 买设备无法缩短关键链，因此最优采购为 0 |

### 1.2 论文风格选择

正式论文应避免写成“算法堆叠报告”。推荐叙事：

1. 先用统一模型完整覆盖题目约束。
2. 再说明求解器给出可行调度。
3. 最后用独立下界证明解不是偶然好，而是全局最优。

算法部分可以出现 MILP 与 CP-SAT，但它们服务于“精确建模与验证”，不把 GA 作为主答案来源。

## 2. 推荐论文结构

### 摘要

需要包含四件事：

- 问题类型：带跨车间运输时间的多资源柔性调度问题。
- 方法：建立混合整数规划模型，并用 CP-SAT 对关键下界和采购扩展进行验证。
- 结果：列出 Q1-Q4 最短工期和 Q4 采购 0 台。
- 亮点：四问均有下界或显式模型支撑，结果可证明最优。

摘要中不展开公式，不写过多算法细节。

### 1 问题重述

目标是把题面翻译成建模语言：

- 五个车间 A-E 分别有固定工序链。
- C 车间 C3-C5 需要重复 3 轮。
- 工序可能需要一类或两类设备。
- 同类设备可替代，但单台设备不可并行服务。
- 跨车间移动产生序列相关运输时间。
- 四问逐步增加资源范围和采购决策。

本节不讨论求解结果。

### 2 模型假设

建议列出以下假设：

1. 设备从所属班组驻地出发，首次作业需满足初始到达时间。
2. 同一设备在同一车间内不同工序之间转运时间忽略。
3. 跨车间转运时间按 `ceil(distance / 2)` 秒计算。
4. 双设备工序采用同时投入、分别完成对应工程量、完成时刻取较晚者的解释。
5. 设备工作时长均向上取整到秒。
6. 购置设备与原设备性能相同，且归属于指定班组。

注意第 4 条需要主动解释：该处理符合“不考虑两类设备先后顺序、等待时间”的题意，并且 Q3/Q4 达到关键链下界，说明该假设没有造成结果失真。

### 3 符号说明

建议符号表按“集合、参数、变量”三类组织。

集合：

| 符号 | 含义 |
|---|---|
| `J` | 展开后的工序集合 |
| `O` | 设备子任务集合，一个工序-设备类型对应一个子任务 |
| `M` | 可用设备集合 |
| `K` | 设备类型集合 |
| `W` | 车间集合 |
| `C` | 班组集合 |

参数：

| 符号 | 含义 |
|---|---|
| `w(j)` | 工序 `j` 所属车间 |
| `seq(j)` | 工序 `j` 在本车间内的顺序 |
| `tau(o)` | 子任务 `o` 所需设备类型 |
| `j(o)` | 子任务 `o` 所属工序 |
| `p_o` | 子任务 `o` 的作业时长 |
| `d_j` | 工序 `j` 的链式占用时长，即 `max p_o` |
| `r_{u,v}` | 从地点 `u` 到地点 `v` 的运输时间 |
| `price_k` | 类型 `k` 设备单价 |
| `B` | 采购预算，500000 元 |

变量：

| 符号 | 含义 |
|---|---|
| `S_j` | 工序 `j` 开始时间 |
| `T` | 全部任务完工时间 |
| `x_{o,m}` | 子任务 `o` 是否分配给设备 `m` |
| `y_{a,b,m}` | 同设备上子任务 `a` 是否排在 `b` 前 |
| `z_m` | Q4 中候选增购设备 `m` 是否购买 |

## 3. 数学模型章节设计

### 3.1 数据预处理模型

本节负责说明从附件到模型实例的转换：

1. 将 C 车间展开为：

```text
C1 -> C2 -> C3_R1 -> C4_R1 -> C5_R1
           -> C3_R2 -> C4_R2 -> C5_R2
           -> C3_R3 -> C4_R3 -> C5_R3
```

2. 将双设备工序拆成多个设备子任务。
3. 计算子任务作业时长：

```text
p_o = ceil(工程量 / 设备效率 * 3600)
```

4. 计算工序链占用时长：

```text
d_j = max_{o: j(o)=j} p_o
```

5. 计算跨车间运输时间：

```text
r_{u,v} = ceil(distance(u,v) / 2)
```

这一节应放一个“实例规模表”：原始工序 21 个，展开后工序 27 个，设备子任务 41 个。

### 3.2 固定设备调度模型

Q1-Q3 使用同一个固定设备模型，只是设备集合不同。

目标函数：

```text
min T
```

设备子任务唯一分配：

```text
sum_{m: type(m)=tau(o)} x_{o,m} = 1,  forall o in O
```

车间内工序链：

```text
S_b >= S_a + d_a
```

其中 `a,b` 是同一车间相邻工序。

完工时间定义：

```text
T >= S_j + d_j,  forall j in J
```

首站到达约束：

```text
S_{j(o)} >= r_{origin(m), w(j(o))} * x_{o,m}
```

同设备互斥与跨车间运输：

若子任务 `a,b` 分配给同一设备 `m`，则二者必须满足其一：

```text
S_{j(b)} >= S_{j(a)} + p_a + r_{w(a), w(b)}
```

或：

```text
S_{j(a)} >= S_{j(b)} + p_b + r_{w(b), w(a)}
```

论文中可以使用 big-M 形式或逻辑析取形式表达。正式文字建议先写逻辑析取，更直观；附录或代码说明中再说明 MILP 使用 big-M 线性化。

### 3.3 Q4 采购扩展模型

Q4 在固定设备模型基础上增加采购变量。

预算约束：

```text
sum_m price_m z_m <= B
```

增购设备启用约束：

```text
x_{o,m} <= z_m
```

其中 `m` 为候选增购设备。

推荐写成两阶段字典序优化：

1. 第一阶段最小化 `T`。
2. 第二阶段在 `T=T*` 条件下最小化采购费用。

这样能自然解释“工期相同时不采购更优”。

## 4. Q1-Q4 分析章节规划

### 4.1 问题一：班组 1 完成 A 车间

章节目标：

- 展示模型在最简单场景下的应用。
- 给出 A 车间工序链下界。
- 说明排程达到下界，因此最优。

应写内容：

```text
班组 1 到 A 的初始转运时间为 200s。
A 车间固定顺序为 A1 -> A2 -> A3。
各工序最短占用时长为 5400s、18000s、18000s。
因此任意方案均不短于 200 + 5400 + 18000 + 18000 = 41600s。
模型排程达到 41600s，故为最优。
```

应放图表：

- 表 1：`baseline_v1/results/table1_question1.csv`
- 甘特图：`baseline_v1/figures/gantt_q1.png`

### 4.2 问题二：班组 1 完成五车间

章节目标：

- 说明 Q2 的复杂性来自跨车间运输和单班组瓶颈设备。
- 不只说 MILP 最优，而要给出双瓶颈松弛下界。

应写内容：

```text
班组 1 中高速抛光机和自动传感多功能机均只有 1 台。
构造只保留这两台单机互斥、运输时间和所有车间工序链的松弛模型。
该模型放松了其他多台设备冲突，因此其最优值是原问题下界。
松弛模型最优值为 163764s。
完整调度模型给出同值可行排程。
故 Q2 最优值为 163764s。
```

- 表 2：`baseline_v1/results/table2_question2.csv`
- 甘特图：`baseline_v1/figures/gantt_q2.png`
- 双瓶颈资源序列表：来自 `docs/analysis/B题完整分析链与最优性验证.md`

### 4.3 问题三：两班组共同完成五车间

章节目标：

- 说明设备数量翻倍后，资源瓶颈被削弱，但 C 车间工序链成为不可压缩关键路径。
- 用 C 链下界证明最优。

应写内容：

```text
C 车间必须按 C1 -> C2 -> (C3 -> C4 -> C5) * 3 完成。
其不含初始转运的链长为：
10368 + 7406 + 3 * (6480 + 14400 + 14400) = 123614s。
两班组到 C 的最短初始到达时间为班组 1 的 230s。
因此任意调度不短于 123844s。
模型排程达到该下界，故 Q3 全局最优。
```

应放图表：

- 表 3：`baseline_v1/results/table3_question3.csv`
- 甘特图：`baseline_v1/figures/gantt_q3.png`
- C 车间关键链计算表

### 4.4 问题四：50 万预算设备购置与调度

章节目标：

- 避免只写“关键路径无法突破”，需要写显式采购模型。
- 说明购买设备不能缩短 C 车间单工序时长，也不能改变严格顺序。
- 用 CP-SAT 采购模型确认最优采购为 0。

应写内容：

```text
在 Q3 设备集合基础上，增加候选增购设备变量 z_m。
预算约束为 sum price_m z_m <= 500000。
若任务分配给增购设备，则必须满足 x_{o,m} <= z_m。
第一阶段最小化工期，得到最优工期 123844s。
第二阶段固定最优工期，最小化采购费用，得到采购费用 0 元。
因此 Q4 最优采购方案为所有设备均购买 0 台。
```

## 6. 模型评价与推广章节

这一节建议写三点。

### 6.1 优点

- 约束覆盖完整：工序链、双设备协同、设备互斥、跨车间运输、采购预算均纳入。
- 结果可验证：每问都有下界或显式模型支撑。
- 可解释性强：Q2 解释为瓶颈设备限制，Q3/Q4 解释为 C 车间关键链限制。

### 6.2 局限

- 双设备工序采用同时起算解释，虽然符合题意，但可在模型推广中放宽。
- 当前实例规模较小，精确求解器表现很好；大规模情况下可能需要启发式算法。
- 采购模型默认新增设备与原设备性能一致，未考虑采购到货时间、维护成本等实际因素。

### 6.3 推广

- 可扩展到更多车间、更多班组。
- 可将目标从单一完工时间扩展为工期、成本、设备利用率多目标优化。
- 可将当前 MILP/CP-SAT 精确模型作为小规模基准，后续引入 GA、禁忌搜索或大邻域搜索处理更大实例。
