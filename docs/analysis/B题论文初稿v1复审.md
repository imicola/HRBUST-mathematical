## 三、严重问题（影响正确性与可复现诚信）

### 🔴 P0-1　模型公式不完整：`y` 变量声明却从未出现在任何约束里

§4.3 定义了排序变量 $y_{a,b,m}$，但 §6.6 设备互斥约束只用**自然语言**「若 a 在 b 前」写成析取：

$$S_{j(b)}\ge S_{j(a)}+p_a+r_{w(a),w(b)} \quad\textbf{或}\quad S_{j(a)}\ge S_{j(b)}+p_b+r_{w(b),w(a)}$$

这**不是可求解的 MILP**。完整形式必须：
- 用 big-M 线性化并显式写出 $y$ 与 $x$ 的耦合项：$S_{j(b)}\ge S_{j(a)}+p_a+r - M(1-y_{a,b,m})-M(2-x_{a,m}-x_{b,m})$；
- 给出「同设备上 a、b 必须排定先后」的 $y_{a,b,m}+y_{b,a,m}=x_{a,m}\cdot x_{b,m}$（或等价线性化）；
- 指明 big-M 取值依据。

评审会一眼看出「定义了变量却不约束」。蓝图 §3.2 计划「正文写析取、附录写 big-M」，但未落地。

> **状态：本次暂缓（用户决策），作为已知项登记，待正式稿 LaTeX 阶段在 `05_model.tex` 补全。**

### 🔴 P0-2　「可复现性」承诺部分失实：5 张甘特图无生成源码

盘点确认：`baseline_v1/code/model_solver.py` 只产 CSV；`create_report.py` 只**引用**已存在的 PNG（不生成）。**全项目无任何 matplotlib / 绘图代码**。而 §11.2、§12.1 优点 4 都宣称「结果表和甘特图可由脚本重新生成」——对甘特图**不成立**。

修法二选一：补绘图脚本（推荐，配合新增图一并补）；或把措辞收敛为「数值结果可复现，甘特图为求解结果的可视化产物」。

### 🟡 P1-1　Q2「全局最优」略过强

§8 称 Q2 = 163764 为「全局最优」。但该下界来自**同样采用假设 4（双设备同时起算）的松弛模型**，证明的是「在假设 4 下的最优」，而非「与假设 4 无关的最优」。§3 第 87 行那段「该处理不影响结论」的辩护**只覆盖 Q3/Q4（C 链下界与假设 4 无关），没覆盖 Q2**。

修法二选一：
- 软化为「本文模型假设下的最优」；
- 或补一句论证：放宽假设 4（双设备异步）不会让 Q2 工期低于 163764（异步也帮不上忙，但需点明）。
