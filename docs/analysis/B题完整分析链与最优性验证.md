## 1. 问题结构抽象

B 题可抽象为带运输时间的多资源调度问题：

- 每个车间内部工序严格按编号顺序执行。
- 同类设备有多台可替代，设备编号唯一，同一时刻只能服务一道工序。
- 部分工序需要两类设备共同参与；两类设备均完成对应工程量后工序完成。
- 同一设备同车间换工序运输时间为 0，跨车间运输时间为 `ceil(distance / 2)` 秒。
- 目标为最小化全部车间完工时间 `Cmax`。

展开 C 车间循环后，实例规模为：

| 项目 | 数量 |
|---|---:|
| 原始工序 | 21 |
| 展开后工序实例 | 27 |
| 设备子任务 | 41 |
| Q1 设备池 | 班组 1 |
| Q2 设备池 | 班组 1 |
| Q3/Q4 设备池 | 班组 1 + 班组 2 |

## 2. 数据与时间计算

每个设备子任务持续时间按题意取整：

```text
p_{j,k} = ceil(工程量_j / 效率_{j,k} * 3600)
```

若工序 `j` 需要多类设备，则工序链约束使用：

```text
d_j = max_k p_{j,k}
```

其中 `k` 为该工序所需设备类型。关键例子：

| 工序 | 设备持续时间 | 工序链占用时间 |
|---|---:|---:|
| A1 | 精密灌装机 5400s，自动化输送臂 4320s | 5400s |
| A2 | 高速抛光机 18000s，工业清洗机 7200s | 18000s |
| C4 | 高速抛光机 12000s，工业清洗机 14400s | 14400s |
| D4 | 高速抛光机 45000s，自动传感多功能机 18000s | 45000s |

## 4. Q1 解析下界

Q1 仅由班组 1 完成 A 车间，A 车间必须按 `A1 -> A2 -> A3` 执行。班组 1 到 A 车间距离 400m，移动速度 2m/s，初始到达时间为 200s。

```text
LB_Q1 = 200 + max(A1) + max(A2) + max(A3)
      = 200 + 5400 + 18000 + 18000
      = 41600s
```

v1 排程达到该下界，故 Q1 全局最优。

## 5. Q2 独立下界：双瓶颈资源松弛

Q2 仅使用班组 1。班组 1 中以下两类设备均只有 1 台，是天然瓶颈：

- 高速抛光机
- 自动传感多功能机

构造一个松弛问题 `R2`：

1. 保留全部 27 个工序的车间内部顺序约束。
2. 保留各工序最短占用时间 `d_j = max_k p_{j,k}`。
3. 保留班组 1 初始到达车间的最早开工约束。
4. 对高速抛光机、自动传感多功能机两台单机，完整保留设备互斥与跨车间转运时间。
5. 放松其他设备类型（自动化输送臂、工业清洗机、精密灌装机）的互斥冲突。

由于 `R2` 删除了部分资源冲突，可行域大于原 Q2，因此其最优值是原问题的合法下界：

```text
OPT(Q2) >= OPT(R2)
```

脚本求得：

```text
OPT(R2) = 163764s = 45:29:24
```

而 v1 完整 MILP 已给出 Q2 可行排程：

```text
OPT(Q2) <= 163764s
```

两者夹逼：

```text
OPT(Q2) = 163764s
```

## 6. Q3 解析下界

Q3 使用两个班组。所有车间中，C 车间工序链不可并行压缩：

```text
C1 -> C2 -> (C3 -> C4 -> C5) * 3
```

不含初始运输的链长为：

```text
C1 10368
+ C2 7406
+ 3 * (C3 6480 + C4 14400 + C5 14400)
= 123614s
```

两班组到 C 车间的最短初始到达时间为班组 1：

```text
460m / 2m/s = 230s
```

故：

```text
LB_Q3 = 123614 + 230 = 123844s
```

v1 Q3 排程达到该下界，故 Q3 全局最优。

## 7. Q4 显式采购模型

Q4 不是只用关键路径口头论证。验证脚本构建了显式采购-调度 CP-SAT 模型：

### 7.1 采购变量

对每个 `(班组, 设备类型)` 建立可购买候选设备，候选数量上限为：

```text
floor(500000 / 设备单价)
```

每台候选设备有二元变量：

```text
z_m = 1 表示购买候选设备 m
```

预算约束：

```text
sum_m price_m * z_m <= 500000
```

### 7.2 调度变量

对每个设备子任务和可选设备建立分配变量：

```text
x_{o,m} = 1 表示子任务 o 分配给设备 m
```

若任务分配给增购设备，则强制购买：

```text
x_{o,m} <= z_m
```

模型同时包含：

- 工序链约束；
- 工序 makespan 定义；
- 设备唯一分配；
- 同设备不重叠；
- 跨车间序列相关转运时间；
- 不同班组设备从不同驻地出发的初始到达时间。

### 7.3 字典序优化

分两阶段求解：

1. 最小化 `Cmax`。
2. 固定最优 `Cmax`，最小化采购费用。

脚本输出：

```text
candidate_machines: 128
candidate_extra_machines: 96
assignment_variables: 1092
pairwise_order_variables: 4208

stage_1_min_makespan:
  status: OPTIMAL
  objective: 123844 s = 34:24:04
  best_bound: 123844 s

stage_2_min_purchase_cost_at_optimal_makespan:
  status: OPTIMAL
  makespan: 123844 s = 34:24:04
  purchase_cost: 0 yuan
  purchased_count: 0
```

因此 Q4 的最终结论为：

```text
最优工期 = 123844s
最优采购费用 = 0 元
最优采购方案 = 各设备均购买 0 台
```

这与 C 车间关键链下界一致：采购只能增加设备并行能力，不能缩短单个工序的 `maxdur`，也不能打破 C 车间严格工序链。
